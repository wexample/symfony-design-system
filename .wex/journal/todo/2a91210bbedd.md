# Un contenu trop long coupé, dépliable sur place : `clamp`

Opened: 2026-11-27
Updated: 2026-11-27
Status: à faire
Author: agent:main (Syrtis), pour l'agent du design system

## Pourquoi

Le widget « Session messages » de Syrtis (le chat de l'éditeur de scénario) affiche chaque
message dans une carte (`session-message`). Un message peut être très long : une réponse de
modèle de plusieurs pages, un markdown, un HTML, un JSON de plusieurs centaines de lignes. Le
fil devient illisible, on ne voit plus qu'un message à la fois.

Syrtis ouvre déjà un message seul, en entier, dans le panel. Il manque, dans le fil, de **couper
ce qui dépasse** et de le **déplier sur place**. Le DS n'a rien pour ça :

- `code-block` a `maxLines`, qui coupe le code sans moyen de le déplier, et ne vaut que pour du code ;
- `disclosure` cache tout son contenu derrière un libellé, il ne montre pas le début ;
- les `line-clamp` du DS (`mixins/_text`) coupent une ligne de texte, pas un bloc quelconque.

Le corps d'un message est un composant parmi une vingtaine (texte, markdown, HTML, `code-block`
JSON, liste, formulaire…) : la coupe doit se faire **autour**, sans savoir ce qu'il y a dedans.

## Ce qui est demandé

Un composant `clamp` (twig et vue) qui enveloppe un contenu quelconque (slot par défaut) :

- une hauteur maximale (prop, une taille du DS ou des lignes ; par défaut de l'ordre de 20 lignes
  de texte courant) ;
- tant que le contenu tient, **rien** : ni dégradé, ni bouton ;
- s'il dépasse : coupé à cette hauteur, le bas fondu vers le fond de ce qui l'entoure, et un
  bouton discret dessous « Tout afficher » qui le déplie sur place ; déplié, « Réduire » ;
- la mesure suit le contenu : un contenu qui grandit après coup (une image chargée, un message
  reçu en direct qui s'allonge) fait apparaître la coupe ;
- ouvert par défaut possible (prop, ou `v-model:open`), pour qu'une page qui veut tout montrer
  n'ait pas à le retirer ;
- le fondu lit le fond du conteneur (une carte, une zone) plutôt qu'une couleur fixe ;
- `prefers-reduced-motion` : pas d'animation de hauteur.

## Où Syrtis s'en servira

`SYRTIS/local/api/front/vue/session-message/session-message.vue.twig` : autour de
`<component :is="bodyComponent">` dans `.block--body`. La page panel qui montre un message seul
(`session-message-single`) le voudra ouvert.

Le JSON n'a pas de repli par nœud dans `code-block` : pas demandé ici, la coupe suffit pour
l'instant.
