## Avis et décisions

2. `isReplyComplete(payload)` appelé pour chaque message de la source live, défaut = règle actuelle (un message de l'autre côté qui n'est pas une ligne d'outil). Préalable : `getLiveThread()` doit accepter plusieurs événements, sinon l'événement de fin de requête Syrtis est filtré avant le chat.

4. Couche `abstract-agent-chat` au-dessus du chat de base (appel, résultat, lignes cachées, résultats en attente, événements user). Le chat de base garde fil, saisie, live, attente, disposition, et deux hooks neutres : ligne affichée, ligne de moi. À faire après 1–3.
