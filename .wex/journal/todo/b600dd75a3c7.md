# Select à recherche distante iso (twig / Vue / dynamic-form)

Opened: 2026-11-05
Updated: 2026-11-05
Author: agent:main (Syrtis)

## Besoin

Syrtis choisit le **type de contenu** d'un message parmi un registre (types de la plateforme et du projet) qui peut devenir très long. Il veut un **select qu'on cherche**, ses options lues d'une API à mesure qu'on tape, et pas toutes envoyées avec le formulaire. La valeur est une chaîne (le nom du type), pas une relation : ce n'est pas le cas de `EntitySearchInputType` (symfony-search), qui poste l'id d'un enregistrement.

Même patron que le champ tags (`ddb58e23958b.md`) : un champ générique du DS, préréglé par Syrtis (`ContentTypeInputType` / `content-type-input`).

## Constat

- `form/select-input` (Vue et twig) : options fournies d'avance (`options` / `choices`), pas de recherche.
- `components/select-search` (twig + ts) : un select cherchable, mais sur ses seules options, sans source distante ni pendant Vue, et hors de la famille `form/*`.
- `SelectInputType` (symfony-forms) : `choices` seulement.
- `FormDefinitionBuilder` / `dynamic-form` : le type `select` envoie et dessine toutes ses `choices`.

## À faire

- [ ] Un select cherchable **iso** twig / Vue (dans `form/select-input` avec une option `searchable`, ou un `form/search-select-input` à part — à trancher par le DS), fusionnant `components/select-search` s'il fait doublon.
- [ ] **Source distante** : `options_url` interrogée avec `?q=` (pause de frappe), réponse `[{ value, label }]` ou chaînes, enveloppée ou non (`data` / `items`), comme les suggestions de `tags-input` — logique écrite une fois (helper partagé).
- [ ] La **valeur courante** affichée par son libellé sans liste complète : le libellé donné avec la valeur (`value_label`), ou demandé à la source.
- [ ] `SelectInputType` : options `options_url` (et `searchable`), passées au form theme ; la validation n'exige pas que la valeur soit parmi des `choices` absentes (la vérification reste au serveur de l'application, contrainte de son choix).
- [ ] Norme des champs : `FormDefinitionBuilder` transmet `options_url` (et le libellé courant) ; `dynamic-form` le dessine.
- [ ] Une version vide de toute option (`choices` vides) quand `options_url` est donné.
