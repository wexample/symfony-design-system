## Objectif

Donner à l'agent des outils exécutés côté serveur, sous l'identité du user, génériques pour toutes les apps (manager Syrtis en cible, portfolio en test). Suite des tools front (849c74de6444).

## Où vit le code (depuis le 30/10)

- `symfony-ai` : couche neutre, ce qu'une app offre à un agent. `AgentBackToolInterface`, `AgentBackToolsService` (resolve, handles, answer, runAs, completeToolList), `AgentTurnCollector`, `AgentRoute`, config `wexample_symfony_ai.agent_tools` (`front`, `back`, `disabled`), `whoami`, `list_pages`, commande `ai:agent-tools`, `LayoutAgentToolsProvider`. Doc : `.wex/knowledge/usage/tools.md.j2`. Tests : 11.
- `symfony-ai-conversation` : les conversations tenues dans l'app (ancien symfony-ai). Adaptateurs : `AgentBackToolListener`, `MessageController::create` complète `list_tools`.
- Manager : adaptateurs `AgentBackToolRelay` (worker `EntityMessageSaveMessageHandler`, `MessageController::create`) et `ToolResultCollector` sur `AgentTurnCollector`.
- Loader : seulement le hook `LayoutRenderDataProviderInterface` et les tools front. DS : rien côté back. `RouteDescription` dans symfony-helpers.

## Décisions

- Interception côté back : l'appel est marqué `runBy: 'back'` avant Mercure, exécuté au nom du propriétaire de la session, renvoyé au moteur ; le front n'exécute pas un appel marqué. Pas de token dans le webhook.
- `list_pages` : seulement les routes `#[AgentRoute]` + `#[RouteDescription]`, puis celles que le user peut ouvrir. Pages d'enregistrement (`{id}`) retirées tant qu'aucun tool ne trouve un id.
- `navigate` : désactivé dans le manager et portfolio (`disabled: [navigate]`), il acceptait toute adresse.
- Une seule emballage `call_tool` reconnu : on fait parler l'agent correctement plutôt que de tolérer.
- Entités : opt-in explicite, voters par enregistrement, écriture via FormType, jamais « n'importe quel champ ». Reporté.

- Le manager doit porter son assistant par `symfony-ai-conversation` + `syrtis/symfony-client` pointés sur lui-même, et garder son api `message/*` purement Syrtis.
